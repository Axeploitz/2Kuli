Taruh file logo di folder ini, lalu tulis nama filenya di src/config/community.js:
  logo: { file: 'logo.png', wordmark: true, invert: true }

wordmark: true -> logo berupa tulisan (nama tidak ditulis ulang di sebelahnya)
invert: true   -> logo hitam di latar putih dibalik jadi putih (untuk latar gelap)

Ikon tab browser (favicon): timpa file favicon.svg di folder ini.
